<h1 align="center">YapYapLand Launcher</h1>

<p align="center">친구들과 함께하는 YapYapLand 전용 Minecraft 런처</p>

## 소개

YapYapLand Launcher는 친구들과 Minecraft 서버를 즐기기 위해 pengisblue가 커스터마이징한 데스크톱 런처입니다. Society: Sunlit Valley 기반의 커스텀 모드팩에 필요한 파일과 설정을 관리합니다.

- 모드팩 파일과 설정 다운로드 및 업데이트
- 게임 실행에 필요한 Java 버전 확인 및 설치 지원
- Microsoft 계정을 통한 Minecraft 로그인
- YapYapLand 서버 선택 및 접속 지원
- 전용 로고, 배경 및 런처 이름 적용

각 플레이어는 Minecraft: Java Edition을 소유한 본인의 Microsoft 계정을 사용합니다. 이 프로젝트는 Mojang 또는 Microsoft의 공식 제품이 아니며, 해당 회사와 제휴 관계가 없습니다.

## About

YapYapLand Launcher is a customized desktop launcher for a Minecraft: Java Edition modded server shared by a small group of friends. It manages a custom modpack based on Society: Sunlit Valley, downloads required files and configurations, and supports signing in with each player's own Microsoft account.

Microsoft authentication is used to verify Minecraft ownership and retrieve the player's Minecraft profile. Each player must own Minecraft: Java Edition.
